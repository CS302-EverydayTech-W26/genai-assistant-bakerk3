Instructions for Web-Based AI Assistant:

To prompt the AI model, add "/prompt/[YOUR PROMPT HERE!]" to the end of the current url. If your prompt is longer than one word, please use "%20" in place of a space between words.

Here's an example: http://localhost:81/prompt/who%20is%20katherine%20baker?
